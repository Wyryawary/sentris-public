# Sentris Public Snapshot

> A curated, Open-Source-safe subset of the Sentris monorepo, crafted for public sharing.

## Contents
* `.codex.md`  
  Developer workflows and tmux/Codex CLI integration guide.

* `docs/CONTEXT/`  
  Design and context documentation, including:
  - `current_goal.md`
  - `current_setup.md`
  - `gameplay_mechanics.md`
  - `glossary.md`
  - `magic_words.md`
  - `repo_details.md`

* `backend/ai.py`  
  FastAPI AI endpoints implementation using Python.

* `scripts/`  
  Utility scripts for Codex CLI workflows, snapshots, and tmux session management.

## Purpose
This repository demonstrates how the Sentris project:

1. Leverages **Codex CLI** to automate common development workflows.
2. Integrates with **OpenAI** models via a minimal FastAPI backend.

All sensitive or proprietary elements (frontend code, database configuration, secrets) have been excluded.
