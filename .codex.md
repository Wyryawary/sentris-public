# Sentris Passport

## Mission

- WE (meaning you: Codex CLI, instructed by me: solo hobby designer) are having a natural language conversation during an interactive Codec CLI session to develop a web based puzzle game experience called Sentris (ssentris.com), using Flutter (web frontend) and Python (backend; api.ssentris.com).

- OUR conversation is taking place on the ‘cdx’ window of the ‘sentris’ tmux session, started with the start_dev_tmux.sh script (tmux list-windows -t sentris | tmux list-panes -a). We aim to use natural language conversations to automate development related tasks by using tmux wrappers to access each tmux <window> and <pane> terminal and carry out development related tasks.

### TMUX Workflows:

Terminal commands should be executed in their respective tmux windows (e.g. Sentris-snt, Senpire-snp, Backend-bnd) using `tmux send-keys`. Avoid SSH into the VM on the current (cdx) pane.


#### Default TMUX Layout

We use a single tmux session `sentris` with the following windows (by default):
- tmp (0): general-purpose terminal (cwd: repo root)
- cdx (1): Codex CLI (interactive Codex CLI session)
- cmd (2): command shell landing in repo root
- snt (3): Sentris game front-end (cwd: sentris_frontend)
- bnd (4): Backend VM session (ssh sentrisbackendvm)
- enp (5): Senpire admin front-end (cwd: senpire_frontend)


#### Common Examples:

- Reading output from a pane (capture-pane):
  ```
  tmux capture-pane -p -S -10 -t sentris:<window>.<pane>
  ```
  Adjust `<window>`, and `<pane>` to target the appropriate session pane.

- Sending commands to a pane (send-keys):
  ```
  tmux send-keys -t sentris:<window> '<command>' Enter
  ```
  Replace `<command>` with your shell command and specify the correct window and pane.


#### Best practices for multi-pane tmux workflows:

- Always use `tmux capture-pane` after a `tmux send-keys` execution to verify the results of the previous execution before sending a new execution request.

- Make sure that all terminal logs are captured (even lengthy download, install, update, etc… logs) and understood before a new terminal command is decided on and sent away. Strategy: if the beginnings of the last `tmux capture-pane` do not show a continuity from the previous `tmux capture-pane`, repeat and capture a longer terminal log history until a full continuity can be established.


## Products

### Sentris

An AI-powered language puzzle experience that challenges players to construct grammatically and semantically correct sentences by arranging AI-generated text blocks on the bottom of a Tetris-style, column separated stacking board (game.dart).


### Senpire

An admin companion app for Sentris, connecting to the same database.


### Backend
The backend is using Python with Fast API and responsible for the AI layer (ai.py) and database operations (db.py).

## Natural-Language Command Triggers

The assistant recognizes messages prefixed with "magicWord:" (case-insensitive). To invoke a command, use:

magicWord: <command>

Refer to docs/CONTEXT/magic_words.md for the full list of available commands and their actions.
