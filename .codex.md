# Sentris Passport

## Mission

- WE (meaning you: Codex CLI, instructed by me: solo hobby designer) are having a natural language conversation during an interactive Codec CLI session to develop a web based puzzle game experience called Sentris (www.ssentris.com), using Flutter (web frontend) and Python (backend; api.ssentris.com).

- OUR conversation is taking place on the ‘cdx’ window pane of the ‘sentris’ tmux session. Default tmux layout in `scripts\start_dev_tmux.sh`. See current layout, e.g. with `tmux list-windows -t sts | tmux list-panes -a`.
- We aim to use natural language conversations to automate development related tasks by using tmux wrappers to access each tmux `window` terminal and carry out development related tasks.


## TMUX Workflows:

- Terminal commands should be executed in their respective tmux windows. E.g.: `tmux send-keys -t sts:<window> '<command>' Enter`
- Use the `gen` tmux window for general terminal actions, so I can see what is happening and we can collaborate efficiently.
- Avoid keeping me in the dark by using the `cdx` pane for terminal commands if appropriate.
- Avoid SSH into the VM on the current (cdx) pane.
- Always capture a long enough terminal history to avoid working with incomplete information. E.g: `tmux capture-pane -p -S -100 -t sts\:2`
- For consecutive terminal actions, use `tmux capture-pane` after each `tmux send-keys` execution to verify the results.
- Clear the working terminal when appropriate to avoid confusion and excess token usage. E.g.: `tmux send-keys -t sts\:2 clear Enter`


## Products

### Sentris
AI-powered language puzzle that challenges players to construct grammatically and semantically correct sentences by arranging AI-generated text blocks on the bottom of a Tetris-style, column separated stacking board (game.dart).

### Backend
The backend is using Python with Fast API and responsible for the AI layer (ai.py) and database operations (db.py).

### Senpire
Admin companion app for Sentris, connecting to the same database.

## Natural-Language Command Triggers

The assistant recognizes messages prefixed with "magicWord:" (case-insensitive). To invoke a command, use:

magicWord: <command>

Refer to docs/CONTEXT/magic_words.md for the full list of available commands and their actions.
